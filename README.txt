# Jzel Bautista - Personal Portfolio

## How to view
1. Extract this ZIP file.
2. Open `index.html` in a web browser.
3. Use the navigation links to visit Home, About, Portfolio, and Contact.

## Files
- `index.html` - Homepage and biography
- `about.html` - Background, education, and skills
- `portfolio.html` - Practice projects and descriptions
- `contact.html` - Contact details and a demo message form
- `css/style.css` - Shared external stylesheet
- `assets/jzel-profile.jpg` - Homepage profile photo
